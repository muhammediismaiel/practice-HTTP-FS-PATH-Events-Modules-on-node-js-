# practice-HTTP-FS-PATH-Events-Modules-on-node-js-

A hands-on implementation of a Native Node.js Server without using any external frameworks like Express. This project demonstrates a deep understanding of the Node.js core modules and how data flows through the server.🧠 What I Practiced in This Project:Manual Routing: Handling different HTTP methods (GET/POST) and URL paths.Stream Handling: Processing POST data using buffers and chunks (The real way Node.js handles data streams).Event-Driven Architecture: Implementing the EventEmitter to decouple logic (triggering a "User Added" event).Asynchronous File System: Using fs to read from and write to the local database (text files).🛠️ Built WithNode.js Core Modules:http: To create the server and handle requests.fs: For persistent data storage in .txt files.path: For managing cross-platform file paths.events: To implement a custom event-driven workflow.🔌 API EndpointsMethodEndpointDescriptionGET/userReads data from uset.txt and returns it to the client.POST/userReceives a data chunk, saves it to user.txt, and emits a userAdd event.🚀 How to RunClone the repository.Run the server using:Bashnode <filename>.js
The server will be live at http://localhost:3000.
